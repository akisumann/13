# ダンジョン13

ブラウザで遊べるターン制ローグライク。地下13階に潜む「**十三階の主**」を討伐するのが目標です。

依存ライブラリなし(バニラ JavaScript + Canvas)。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

### キーボード

| 操作 | キー |
|---|---|
| 移動 | 矢印キー / WASD / hjkl |
| 攻撃 | 敵に向かって移動(体当たり) |
| 待機 | Space または `.` |
| 回復薬を飲む | Q |
| 階段を降りる | `>` または Enter |
| リスタート | R(ゲームオーバー時) |

### スマホ・タブレット(タッチ)

タッチ端末では画面下に操作ボタンが表示され、マップはプレイヤー周辺を拡大表示します。

| 操作 | 方法 |
|---|---|
| 移動 | 画面スワイプ or 十字ボタン(長押しで連続移動) |
| 待機 | 「・」ボタン |
| 回復薬 / 階段 | 専用ボタン |
| リスタート | ゲームオーバー時に画面タップ |

## ルール

- マップは毎回ランダム生成。視界(半径8マス)の外は霧に包まれています。
- 各階の下り階段 `>` を見つけて地下13階を目指します。深く潜るほど敵が強くなります。
- 敵を倒すと経験値が入り、レベルアップで最大HPと攻撃力が上昇します。
- 6ターンごとにHPが1自然回復します。
- 地下13階に階段はありません。ボス「十三階の主」を倒せばクリアです。

## アイテム

| 記号 | アイテム | 効果 |
|---|---|---|
| `!` | 回復薬 | 拾って持ち歩き、Qで飲むとHP回復 |
| `/` | 武器 | 拾うと自動装備(強い方を優先) |
| `]` | 盾のかけら | 防御+1(恒久) |
| `¤` | 生命の秘薬 | 最大HP+4 & 全回復 |
| `$` | 金貨 | スコア |

## 開発

ビルド不要。`index.html` / `style.css` / `game.js` の3ファイル構成です。

ロジックのスモークテストは DOM スタブを使って Node で実行できます(リポジトリには含めていません)。
