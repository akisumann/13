# モンスターマスター

モンスターを配合して新種を生み出すブラウザゲーム。スマホ縦持ち前提。
依存ライブラリなし(バニラ JavaScript)。`index.html` を開くだけで遊べます。

進行状況は `localStorage` に自動保存されます。

## コアループ

```
探索でモンスターと金貨を集める → 同ランク2匹を配合して1つ上のランクへ
   ↑                                              ↓
   └────────── 強い個体で更に深いエリアへ ←────────┘
```

## 5つのタブ

| タブ | できること |
|---|---|
| 牧場 | にわ(全員がうろうろしている)、手持ちの一覧・名前づけ・系譜・にがす、商店 |
| 配合 | 2匹を選んで新しい1匹を生む。生まれる種を事前にプレビュー。触媒で結果を制御できる |
| 探索 | エリアと編成(最大3匹)を選び、自動でパーティ戦。経験値・金貨・仲間を得る |
| 大会 | 3匹で勝ち抜き戦。傷を持ち越したまま最大5回戦を戦い、優勝で賞金と記録 |
| 図鑑 | 発見した種の記録(全29種)と、種ごとの本来スキル・解説文、ステータスとスキルの一覧 |

## 配合のルール

**ランク** — 同じランクどうしを配合すると、ランクが1つ上がる(最大5)。
ランクが違う場合は高いほうを引き継ぐだけなので、**同ランクを2匹そろえるのが昇格の唯一の道**です。

**系統** — 親2匹の系統の組み合わせで子の系統が決まります。

| 親の組み合わせ | 子 |
|---|---|
| 同じ系統どうし | 同じ系統 |
| 炎 + 水 | 風 |
| 炎 + 草 | 炎 |
| 炎 + 岩 / 岩 + 風 | 岩 |
| 水 + 草 / 草 + 岩 | 草 |
| 水 + 岩 / 水 + 風 | 水 |
| 草 + 風 | 風 |

隠し系統が2つあります。

- **闇** — ランク3以上の異なる系統どうしを配合すると、25%で発現。以降は闇が親なら子も闇。
- **光** — 闇のランク4以上どうしを配合すると誕生(ランク5固定・全ステータス上昇)。

**遺伝** — 子は親のレベルと遺伝値を引き継ぎます(`(親の遺伝値の平均) + (親のレベル合計 ÷ 4)`)。
親をレベル上限まで育ててから配合すると子が強くなり、**代を重ねるほど強くなる**のがこのゲームの背骨です。

## ステータスと常時効果

7種類あります。値は「種のランク × 系統補正 + レベル × 成長係数 + 遺伝値」で決まります。

**7つすべてが常時発動の効果を持ちます。**呪文の詠唱もMPの消費コマンドもありません。

| 表示 | キー | 常時効果 |
|---|---|---|
| HP | `hp` | 0になると負ける |
| MP | `mp` | **魔力よろい** — 被ダメージの55%をMPが肩代わりする。尽きるまでの盾なので、**多いほど有利**(合計の耐久力は HP + MP) |
| こうげき | `atk` | 与えるダメージ |
| ぼうぎょ | `def` | 受けるダメージを減らす(`atk²/(atk+def)` の割合軽減) |
| かしこさ | `int` | **見切り** — 相手とのかしこさの比だけ、与ダメージが増え被ダメージが減る |
| すばやさ | `spd` | **すばやさの比の確率で先手**を取る。差が大きいほど**追撃**(続けてもう一撃)も出る |
| きようさ | `dex` | **受け流し** — 相手とのきようさの比に応じた確率で、ダメージを35%に抑える |

### MPが低いことは、はっきり不利

MPは素直に「多いほど強い」ステータスです。他をすべて同じにしてMP補正だけを変えると、
0.70で勝率63%、1.00で73%、1.40で86%と単調に上がります。

そのうえで、MPが薄い系統(岩)には**他の6項目を底上げして**釣り合いを取っています。

| | MP補正 | 他6項目の平均 |
|---|---|---|
| 岩 | **0.81**(最低) | **1.171**(最高) |
| 他の基礎系統の平均 | 1.14 | 1.145 |

埋め合わせは控えめで、補正の総和で見ると岩(7.81)は水・草・風より下です。
MPの薄さという弱点は残したまま、地力で押す系統として成立させています。

### すべて「相手との比」で効く

見切り・受け流し・追撃はいずれも絶対値ではなく相手との比で決まります。
絶対値のしきい値だと、数値の小さい低ランクでは効かず、高ランクでは効きすぎるためです。
この方式ならランク1でもランク5でも同じように働きます。

## 成長係数(F〜S)

ステータスごとに **F・E・D・C・B・A・S の7段階**の成長係数があり、レベルアップでの伸びやすさを決めます。

- **種族としての固定値です。** 遺伝値やレベル、育て方では一切変わりません。同じ種なら誰でも同じ係数です。
- 効くのは**レベルぶんの伸びだけ**。遺伝値は係数と無関係にそのまま加算されます。
- 系統の得意不得意とランクを元に決めてあり、**ランクが低い種ほど全体的に低く**なります。
- `SPECIES` に文字列(例: ゴーレットなら `AEBADDD`)として直接持たせています。系統補正から
  計算で出すと、補正を少し触っただけでグレードが飛んでバランス調整が階段状になるためです。

| グレード | F | E | D | C | B | A | S |
|---|---|---|---|---|---|---|---|
| 1レベルあたりの倍率 | 0.45 | 0.65 | 0.85 | 1.05 | 1.3 | 1.6 | 1.95 |

ランクごとの平均と分布:

| ランク | 平均倍率 | 出現するグレード |
|---|---|---|
| 1 | 0.73 | F〜B(A・Sは出ない) |
| 2 | 0.90 | F〜A |
| 3 | 1.15 | E〜S |
| 4 | 1.38 | D〜S |
| 5 | 1.62 | C〜S(F・Eは出ない) |

同じランクでも系統で偏ります。たとえばランク3なら、シルフィード(風)はすばやさS・きようさA、
ゴーレット(岩)はぼうぎょA・かしこさD。**低ランクの高係数を伸ばすか、高ランクの平均値を取るか**という
選択が生まれます。ルクスノヴァ(光)だけは7つすべてがSで、唯一の弱点なしです。

係数は牧場の詳細画面で各ステータスの右に表示され、配合プレビューでも生まれる子の得意2つが見えます。

## 系統ごとの特徴

同ランクの総当たりで勝率がそろうよう数値探索で調整してあります。
「どのステータスが高いか」という形が系統の個性で、全体の底上げ量だけを動かしました。

| 系統 | 戦い方 | 高い | 低い | 実測勝率 |
|---|---|---|---|---|
| 炎 | 一撃が重いが打たれ弱い | こうげき、かしこさ | ぼうぎょ、HP | 49% |
| 水 | 魔力よろいが厚く粘る | MP、HP、かしこさ | こうげき、すばやさ | 46% |
| 草 | 守りとMPで長期戦 | ぼうぎょ、MP | こうげき | 46% |
| 岩 | MPは薄いが地力で押す | HP、ぼうぎょ、こうげき | MP、すばやさ、かしこさ | 49% |
| 風 | 追撃と受け流しで手数勝負 | すばやさ、きようさ | HP、ぼうぎょ | 51% |
| 闇 | 見切りで一方的に削る | かしこさ、MP | HP、ぼうぎょ | 56% |
| 光 | 素の補正は控えめだが、**唯一すべての成長係数がS**。育てるほど突き放す | 成長性すべて | — | 63% |

※ 勝率はスキルを含めた同ランク総当たりの実測値です。

## スキル

各モンスターは1〜2個のスキルを持ちます。

**スキル合計値 = レベル ÷ 2**（切り捨て、各スキルの上限はLv.10）。この合計値を持っているスキルで
分け合うので、**1つに絞れば高レベル、2つ持てばその分1つあたりが下がります**。

| モンスターのレベル | 合計値 | 1つだけ | 2つ持ち |
|---|---|---|---|
| 9（ランク1上限） | 4 | Lv.4 | Lv.2 + Lv.2 |
| 15（ランク3上限） | 7 | Lv.7 | Lv.4 + Lv.3 |
| 21（ランク5上限） | 10 | **Lv.10** | Lv.5 + Lv.5 |

低レベルのうちは合計値が足りず、スキルは「未発現」のまま眠っています。

### 習得

- **配合** — 親から**ランダムに0〜2個**受け継ぎます。2個なら両親から1つずつ、1個ならどちらかの親から。
  0個だった場合は、生まれた子の**種族が本来よく持つスキル**を1つ覚えます。
- **野生・たまご** — その種族本来のスキルを1つ持って現れます。

1回の配合で受け継ぐのは最大2個なので、世代を重ねてもスキルが際限なく増えることはありません。

### 一覧（表記はLv.10のとき）

| スキル | 効果 |
|---|---|
| 剛腕 | こうげき +13% |
| 鉄壁 | ぼうぎょ +45% |
| 韋駄天 | すばやさ +30% |
| 明鏡 | かしこさ +30% |
| 巨躯 | HP +35% |
| 魔泉 | MP +55% |
| 会心 | 26%の確率で1.8倍のダメージ |
| 反撃 | 受け流したとき、こうげきの32%で反撃 |
| 吸収 | 与えたダメージの36%だけHPが回復 |
| 毒牙 | 22%の確率で毒（毎ターン最大HPの4.0%。**削り量がレベルで伸びる**） |
| 不屈 | HPが1/4以下のあいだ こうげき +85% |
| 先制 | 90%の確率ですばやさに関わらず先手を取り、追撃が出やすくなる（+16%） |

伸び幅がばらばらなのは、ダメージ式の中での効き方が違うためです（こうげきは二乗で効くので小さく、
ぼうぎょは逓減するので大きく取ってある）。**スキル同士の総当たりで勝率が46〜57%に収まる**よう
数値探索で調整してあります。

### 効果は必ずレベルに比例させる

「合計値をレベルの半分にして、複数持つと分け合う」という設計は、**効果がレベルに比例していること**が
前提です。比例していない効果があると、半分のレベルでほぼ満額の効果が手に入る抜け道になります。

実際、最初の実装では次の3つがそうなっていました。

| 抜け道だったもの | 直し方 |
|---|---|
| 毒のダメージが最大HPの2.5%固定で、レベルは付与確率しか上げなかった | 付与確率を22%固定にし、**削り量をレベル比例**に |
| 先制の「必ず先に動く」がレベルに関係なく発動していた | **レベル×9%の確率**で先手を奪う形に |
| 先手が「すばやさで上回れば確定」だったので、わずかな差で先手が取れた | **すばやさの比の確率**で先手を決めるように |

直す前は「毒牙+先制（各Lv.5）」が最強で、単独全振りの平均47%に対し2つ持ちが51%と、
**分割したほうが有利**というゆがみが出ていました。直したあとは単独49%・2つ持ち50%でほぼ互角です。

### 種族が本来よく持つスキル

**29種それぞれに3つずつ**割り当ててあります。同じ系統でも種によって顔ぶれが違うので、
ヒノコとヴォルケインでは覚えるものが変わります。図鑑の発見済みマスに表示されるので、
配合先を決める材料になります。

| 系統 | R1 | R2 | R3 | R4 | R5 |
|---|---|---|---|---|---|
| 炎 | 剛腕・会心・韋駄天 | 剛腕・会心・不屈 | 剛腕・不屈・毒牙 | 剛腕・会心・明鏡 | 剛腕・不屈・巨躯 |
| 水 | 魔泉・吸収・鉄壁 | 魔泉・鉄壁・巨躯 | 魔泉・吸収・明鏡 | 魔泉・明鏡・先制 | 魔泉・吸収・巨躯 |
| 草 | 鉄壁・巨躯・吸収 | 鉄壁・毒牙・反撃 | 鉄壁・毒牙・明鏡 | 鉄壁・巨躯・吸収 | 鉄壁・巨躯・毒牙 |
| 岩 | 巨躯・鉄壁・不屈 | 巨躯・不屈・剛腕 | 巨躯・鉄壁・反撃 | 巨躯・剛腕・不屈 | 巨躯・鉄壁・剛腕 |
| 風 | 韋駄天・先制・会心 | 韋駄天・反撃・会心 | 韋駄天・先制・反撃 | 韋駄天・会心・剛腕 | 韋駄天・先制・剛腕 |
| 闇 | — | — | 明鏡・毒牙・吸収 | 明鏡・吸収・先制 | 明鏡・毒牙・会心 |
| 光 | — | — | — | — | 明鏡・巨躯・先制 |

系統の看板スキル（炎なら剛腕、水なら魔泉、風なら韋駄天）は全ランクに入れつつ、
残り2つをランクごとに変えてあります。12種すべてがどこかの種に割り当てられています。

## 戦いを見せる

探索の結果欄が、戦っているあいだは**舞台**になります。左が手持ち、右が野生。
HPの帯が減っていき、殴った側がのそのそ寄っていって戻る。

**勝敗も数値も `battle()` でもう決まっています。** 画面がやっているのは、その記録を
順に再生することだけです。だから見せ方をどう変えても釣り合いは動きません。

そのために `battle()` が文字のログと一緒に**構造化した記録**も返すようにしました。

```
{ k:'hit', from:['a',0], to:['b',1], dmg:39, hp:63, crit:false, parry:true, text:'…' }
{ k:'poison', to:['a',0], dmg:7, hp:41, text:'…' }
{ k:'down', to:['b',1], text:'…' }
```

動きの速さは**にわと同じのそのそした間合い**(1手0.78秒)にしてあります。
素早い殴り合いにすると、常時効果だけで組んだこの戦闘の「じわじわ削れる」感じと合いません。

### 見せる / 見せない

探索は連打する場所なので、**切り替えを付けてあります**。入りだと1回に十数秒かかるので、
稼ぎたいときは切れば結果だけがすぐ出ます。設定はセーブされます。

飛ばすボタンは下の固定バーに置いてあります(枠に入れると溢れるうえ、
連打しているときに指を動かさずに済む)。

## パーティ戦

探索には**最大3匹**まで連れて行けます。**連れて行った数だけ野生も出てくる**ので、
1対1・2対2・3対3のいずれも五分の勝負になります（実測48〜51%）。

戦闘は同時戦です。毎ラウンド、生きている全員がすばやさ順に行動し、生きている敵をランダムに狙います。
行動順はすばやさを速度とする競争で決めるので、**先に動ける確率がすばやさの比とちょうど一致**します
（1対1のときと同じ理屈）。

### 経験値は山分け

倒した野生の経験値を合計し、**編成した全員で山分け**します。倒れた仲間も受け取ります。

野生もこちらと同数出るため合計も人数分になり、**1匹あたりの取り分は1匹で行ったときと同じ**です。

| 編成 | 野生 | 1匹あたりの取り分 |
|---|---|---|
| 1匹 | 1匹 | +80 |
| 2匹 | 2匹 | +80 |
| 3匹 | 3匹 | +80 |

つまり1タップあたりの育成効率が人数分になります。配合には「同ランク2匹をレベル上限まで育てる」
必要があるので、ここが一番効きます。

金貨と捕獲の判定は探索1回につき1度のままなので、経済と牧場の圧力は変わりません。

## 大会

探索が「1戦だけ勝てばいい」のに対し、大会は**勝ち抜き戦**です。違いはひとつだけで、
**回戦のあいだ傷が残る**こと。

- **MPは回戦ごとに全快する。** 魔力よろいは休めば張り直せる
- **HPは最大値の25%しか戻らない。** 受けた傷は最後まで付いて回る
- **倒れた仲間はその大会のあいだ戻らない。** 3対3が3対2になり、次の回戦はさらに苦しくなる
- 毒は回戦をまたがない

この一点だけで、探索とはまったく別の物差しがはたらきます。
一撃の重さより、**削られにくさと立て直しの効くスキル**が要ります。

| 大会 | ランク | 回戦 | 優勝賞金 |
|---|---|---|---|
| 新芽杯 | 1 | 2 | 150 G |
| 沼地杯 | 2 | 3 | 420 G |
| 岩窟杯 | 3 | 4 | 1000 G |
| 尖塔杯 | 4 | 4 | 2200 G |
| 虚無杯 | 5 | 5 | 5000 G |

そのランク以上のモンスターを持っていると出場できます。**必ず3匹そろえる必要があり**、
相手も毎回戦3匹出てきます。優勝できなくても、勝った回戦のぶんだけ賞金を持ち帰れます。

**虚無杯の決勝には光(ルクスノヴァ)が出てきます。** 光を作って終わりではなく、
作った光で光に勝つところまでが最後の目標です。

### 3匹そろえないと勝てない

パーティ戦は「まとめて育つから早い」だけの仕組みでしたが、大会では編成そのものが問われます。

| 岩窟杯に出す編成(いずれもランク3・上限まで育成) | 優勝率 |
|---|---|
| 3匹とも育てきり | 49% |
| 2匹だけ | 0% |
| 1匹だけ | 0% |
| 1匹に集中(他2匹はレベル半分) | 0% |

同じ編成で探索(岩窟回廊)に行けば**勝率100%**です。1戦なら通る戦力でも、
4回戦は抜けられません。

### 得意不得意がはっきり出る

探索での系統別勝率は46〜63%に収まるよう調整してありますが、大会では消耗戦になるため
差が開きます(虚無杯・単一系統3匹での優勝率)。

| 炎 | 水 | 草 | 岩 | 風 | 闇 | 光 |
|---|---|---|---|---|---|---|
| 32% | 33% | 35% | 21% | 16% | 37% | 50% |

風は追撃と受け流しで手数を稼ぐ系統なので、長丁場では削られ負けします。
逆に闇は見切りで一方的に削り、吸収を持てば立て直せる。**これは意図した差**で、
「探索向きの編成」と「大会向きの編成」を分けるためのものです。

### 相手はこちらの編成に合わせて作られる

**遺伝には上限がありません。** 上限まで育てたランク5どうしを配合するたびに +10 され、
代を重ねるほど際限なく伸びます。

| 代 | 1 | 2 | 3 | 4 | 5 | 6 | 8 | 10 |
|---|---|---|---|---|---|---|---|---|
| 遺伝 | 26 | 36 | 46 | 56 | 66 | 76 | 96 | 116 |
| ランク5・Lv上限の総合力 | 669 | 739 | 809 | 879 | 949 | 1019 | 1159 | 1299 |

だから相手を固定値で置くと、数代重ねただけで置いていかれて大会が作業になります。
そこで**出場した編成の平均を基準に相手を作ります**。回戦が進むほどこちらに近づき、
決勝ではこちらと同じところまで配合を詰めた相手が出てきます。

それでも五分にならないのは、**傷を持ち越すのがこちらだけ**だからです。

| 出場した編成の遺伝 | 16 | 36 | 66 | 96 |
|---|---|---|---|---|
| 虚無杯の優勝率 | 25% | 30% | 30% | 30% |

**何代重ねても手ごたえが変わりません。** 逆に、育てるほど不利になることもありません
(上乗せを倍率にすると、遺伝が増えるほど差額まで膨らんでそうなります)。

| 大会 | 新芽杯 | 沼地杯 | 岩窟杯 | 尖塔杯 | 虚無杯 |
|---|---|---|---|---|---|
| 育てきり3匹での優勝率 | 52% | 61% | 49% | 42% | 31% |

**上の大会ほど難しく、虚無杯は3回に1回**です。

相手のレベルは**相手自身のランクの上限で止まる**ので、格上のランクを持ち込めば
下位の大会はこれまでどおり100%勝てます。
逆に、わざと格下で出て賞金だけ取ることはできません(相手には大会のランク相応の下限があります)。

## 商店

**金で買えるのは「材料と制御」だけで、ステータスそのものは売っていません。**

このゲームの釣り合いは全部「遺伝とレベル」を基準に組んであります。系統ごとの勝率も、
大会の相手も、こちらの遺伝を見て決まる。装備のような形で外側から数値を足すと、
大会の相手だけが装備を持たないので難度が丸ごと崩れます。

### たまご

| | おまかせ | 系統を指定(×2.5) |
|---|---|---|
| ★1 | 60 G | 150 G |
| ★2 | 260 G | 650 G |
| ★3 | 950 G | 2375 G |

**遺伝は必ず 0** です。強さは配合で積むもので、金で買えるのは材料まで。
買った★3を2匹そろえて配合しても、育てて配合した★4より遺伝は低くなります。

系統を指定できるのは**図鑑に載っているものだけ**です(先の内容が漏れないように)。
闇と光は売っていません。

### 配合の触媒

1回の配合につき1つずつ使えます(使い切り)。**戦闘の数値には一切触りません。**

| 触媒 | 値段 | 効果 |
|---|---|---|
| 闇招きの香 | 320 G | ランク3以上の異系統配合で、25%の闇の発現を確実にする |
| 継承の証 | 220 G | 親からスキルを2つ受け継がせる(通常は20%で0個、40%で1個) |
| 系統の錠 | 260 G | 異系統配合でも、子の系統を**1匹目**のほうに固定する |

いちばん運任せだったのが配合でした。闇が出るかは25%、スキルを何個継げるかは20/40/40。
**そこを金で買えるようにしたので、探索で稼ぐ意味が「配合を狙い撃つため」に変わります。**

配合プレビューは触媒を織り込んで表示します。香や錠を使うと結果が確定するので、
「まれに別の系統が出る」の但し書きも消えます。

### 牧場を広げる

12匹から、1段2匹ずつ4段まで(500 / 1200 / 2800 / 6400 G)。上限20匹。

### 稼ぎとのつり合い

| エリア | 1回の稼ぎ | 触媒1つ | ★3のたまご |
|---|---|---|---|
| はじまりの草原 | 15 G | 21回 | 63回 |
| 岩窟回廊 | 60 G | 5回 | 16回 |
| 虚無の深淵 | 195 G | 2回 | 5回 |

商店を使わずに光まで到達すると、手元に **3300〜8900 G** 残ります。
牧場を上限まで広げると 10900 G なので、金は最後まで足りきらない程度に置いてあります。

## 性格

同じ種でも個体で差が出ます。**1つ得意で1つ苦手**、振れ幅は ±6%。

全15種類あり、**全体では釣り合うように組んであります**。
7つのステータスそれぞれが「得意」に2回・「苦手」に2回ずつ現れるので、
性格を平均すると素の値に戻る。野生も大会の相手も同じように性格を持つので、**難度は動きません**。

| | 得意 | 苦手 | |
|---|---|---|---|
| ずぶとい | HP | MP | 構わず突っ込んだ |
| しんちょう | MP | こうげき | 力を溜めてから放った |
| むこうみず | こうげき | ぼうぎょ | 待たずに飛びかかった |
| がんこ | ぼうぎょ | かしこさ | 動かずに受けてから打った |
| れいせい | かしこさ | すばやさ | 先を読んで差し込んだ |
| せっかち | すばやさ | きようさ | 誰より早く仕掛けた |
| きよう | きようさ | HP | 狙いすまして当てた |
| のんき | HP | ぼうぎょ | のっそりと踏み込んだ |
| ゆめみがち | MP | かしこさ | ぼんやりしたまま振った |
| ちからづく | こうげき | すばやさ | 大振りに叩きつけた |
| ずんぐり | ぼうぎょ | きようさ | 体ごとぶつかった |
| りこう | かしこさ | HP | 間合いを測って打った |
| せかせか | すばやさ | MP | 休まずに手を出した |
| こまやか | きようさ | こうげき | 細かく刻んで当てた |
| まっすぐ | — | — | まっすぐ打ち込んだ |

右端は戦闘ログの言い回しです。**同じ数字でも、誰が出した数字かが読める**ようになります。

### 振れ幅の決め方

同じ種どうしで性格だけを変えて総当たりしたときの勝率:

| 振れ幅 | 最強 | 最弱 |
|---|---|---|
| ±12% | むこうみず 71% | こまやか 25% |
| **±6%** | **むこうみず 61%** | **こまやか 35%** |

こうげきはダメージ式の中で二乗で効くので、こうげきを上げる性格が素直に強くなります。
±12%だと**性格が種より効いてしまう**ので、±6%に落としました。
当たりを狙う意味はありつつ、外れを引いても使い物になります。

### 受け継ぎ

配合では**親のどちらかの性格を継ぎ**、20%でどちらでもないものが出ます。
系譜と噛み合うので、「アカの子は気が短い」が実際に起きます。

## にわ

牧場の頭で、**手持ち全員がうろうろしています。** 取り分も報酬もありません、ただの眺めです。

- 1.1秒ごとに位置が変わり、CSS の transition で滑って移動する
- 進む向きに合わせて左右が反転する
- ときどきその場でうずくまる(少し潰れて薄くなる)
- 近づくと絡む。**言い方は性格で変わる** — こうげき自慢は「じゃれついた」、
  ぼうぎょ自慢は「前にどっかり座った」、MP自慢は「寄り添っている」
- 落ち着きの無さも性格しだい。すばやさ自慢はよく動き、HP・ぼうぎょ自慢は腰が重い

### かけっこ

牧場の遊び。手持ちから最大6匹が勝手に選ばれて走ります。

**ステータスは一切見ません。** 強い個体が勝つ仕組みにすると、遊びではなく順位表に
なってしまうので。性格も速さには関わらず、走り方の描写だけが変わります
(「ぴょんぴょん跳ねながら」「どっしりと」など)。

### 走路は4区間

代わりに、**走るたびに走路の条件が変わります。** 7種類から4つを引いて並べ、
区間ごとに得意な系統(×1.35)と苦手な系統(×0.70)が決まります。

区間は**系統と性格の両方**を見ます。性格の効きは系統より小さく(×1.18 / ×0.85)、
両方そろった個体がいちばん伸びます。

| 区間 | 系統 | 性格 |
|---|---|---|
| 草原 | 草↑ 岩↓ | すばやさ↑ HP↓ |
| 水路 | 水↑ 炎↓ | MP↑ こうげき↓ |
| 岩場 | 岩↑ 風↓ | ぼうぎょ↑ すばやさ↓ |
| 風道 | 風↑ 草↓ | きようさ↑ ぼうぎょ↓ |
| 火床 | 炎↑ 水↓ | こうげき↑ MP↓ |
| 暗がり | 闇↑ 光↓ | かしこさ↑ きようさ↓ |
| 陽だまり | 光↑ 闇↓ | HP↑ かしこさ↓ |

**どの系統も、どのステータスも、「得意」に1回・「苦手」に1回ずつしか出てきません。**
だからたくさん走らせれば誰も得をしない。でも1回のレースでは、引いた条件で
今日の本命が変わります。〈まっすぐ〉は得も損もしません。

実測(各500回):

| | 勝率 |
|---|---|
| 水路づくし・水 対 岩 | 98% |
| 岩場づくし・水 対 岩 | 1% |
| どちらとも関係ない区間・水 対 岩 | 51% |
| 草原づくし・せっかち 対 のんき(同じ系統) | 99% |
| 関わらない区間・せっかち 対 のんき | 46% |
| 岩場づくし・ぼうぎょ自慢の岩 対 すばやさ自慢の岩 | 100% |

**同じ系統・同じ性格なら、強さの差があっても五分のまま**です(実測49%)。

道中の出来事も、有利と不利を同数・同確率で引きます。

| 出来事 | 進み |
|---|---|
| ぐんと伸びた / 外から追い上げた / 前に出た | +6 / +4 / +3 |
| よそ見をした / つまずいた / 立ち止まってしまった | −3 / −4 / −6 |

1着になった回数だけ、その個体の詳細に「かけっこ ○勝」として残ります。
賞金も経験値もありません。

実測で、**最強の個体(ルクスノヴァ Lv.21 遺伝40)と最弱の個体(ヒノコ Lv.1)を
600回走らせて勝率50%**です。

> 途中で1つバグを見つけました。同じ歩でゴールしたとき、走路の並び順で
> 上のレーンが勝っていた(格上の勝率が59%になっていた)。踏み込んだ距離で
> 順位をつけるように直してあります。

### かけっこは持ち出せる

走りの中身は `race.js` に分けてあり、**このゲームを一切参照しません。**
`game.js` 側に残っているのは、牧場のモンスターを走者に均して、
終わったら勝ち数を書き戻すだけのつなぎです。

レースが知っている走者は4つの値だけです。レベルも遺伝も渡していません。

```js
{ id: 'a1', name: 'ぽち', family: 'grass', up: 'spd' }
```

| | |
|---|---|
| `id` | 見分けがつけばなんでもいい |
| `name` | 実況に出る名前 |
| `family` | 区間の相性に使う系統(fire/water/grass/rock/wind/dark/light) |
| `up` | 区間の相性に使う得意ステータス(hp/mp/atk/def/int/spd/dex、無しは null) |

```js
const r = Race.make(runners);
while (!r.over) Race.step(r);      // r.note に実況、r.done に着順
```

- **状態はただのデータ。** `Race.make()` が返すものは配列とオブジェクトだけなので、
  `JSON.stringify` でそのまま保存でき、読み戻して続きから走らせられます
- **乱数は差し替えられる。** `Race.step(r, { rnd })` に0〜1を返す関数を渡すと、
  同じ種なら同じレースになります(検証や再生に使えます)
- **区間も決め打ちできる。** `Race.make(runners, { legs })` で条件を固定できます
- 表もそのまま持ち出せます — `Race.LEGS` / `Race.EVENTS` / `Race.STYLE` は
  全部ただの配列とオブジェクトで、`JSON.stringify(Race.LEGS)` で吐けます
- 系統とステータスの表示名は `Race.LABEL` に自前で持っているので、
  ゲームの `FAMILIES` / `STATS` が無くても表示できます(ずれていないかはテストで見ています)

`race.html` が単体で動く見本です。`race.js` だけを読み、ページの先頭の
`RUNNERS` を書き換えれば別の走者に入れ替わります。

### にわの敷地と器具

商店で買えます。**買えるのは見た目だけで、戦闘の数値には一切関わりません。**
ステータスを売らないのと同じ理由で、代わりに眺めを売っています。

敷地は5種類(草地・砂地・石畳・水辺・星天)。**一度買えば何度でも張り替えられます。**

### 地形

器具と違って**面で広がり**、上に乗ったモンスターの様子が変わります。敷けるのは4つまで。

| 地形 | 値段 | 寄る | 乗ると |
|---|---|---|---|
| 草はら | 600 G | 草 | — |
| 水たまり | 850 G | 水 | 濡れる |
| 岩肌 | 1000 G | 岩 | 高いところに立つ |
| 焚き跡 | 1200 G | 炎 | — |
| 段差 | 1500 G | 風 | 高いところに立つ |
| 洞窟 | 2000 G | 闇 | **姿が隠れる** |

にわは 22×11 のタイルで、地形は並び順から決まる位置に楕円状に広がります。
**いつ見ても同じ形**で、縁の上側だけ明るく塗ることで面に厚みを出しています。
敷地も含めて1枚の絵にまとめ、data URL にして持っています。

> シズク が 水たまり を のぞきこんだ
> ゴーレット が 岩肌 に よじ登った
> ニュクス が 洞窟 の奥から見ている

### 器具

器具は10種類、にわに置けるのは6つまで。

| 器具 | 値段 | 寄ってくる |
|---|---|---|
| 敷物 | 300 G | だれでも |
| まり | 380 G | 風 |
| えさ箱 | 450 G | だれでも |
| 水おけ | 520 G | 水 |
| 丸太 | 560 G | 草 |
| 茂み | 620 G | 闇 |
| とまり木 | 700 G | 風 |
| あたたか石 | 820 G | 炎 |
| 積み石 | 900 G | 岩 |
| 灯明 | 1100 G | 光 |

置くと**その系統のモンスターが寄っていき**、そばに来ると器具ごとの仕草をします。

ただし**3匹たかっていたら、それ以上は寄っていきません。** 全員が同じ器具に吸い寄せられると
ダマになって見ていて面白くないので、混んでいる先は避けて普通にうろつきます。

数えるのは「もう着いている数」だけでは足りません。それだと同時に向かっている連中が誰も
弾かれず、全員が着いてしまう。**向かっている最中のぶんも数に入れています。**

着いた子も居座りません。少し居たら満足して離れ、しばらくは他を回ります
(そうしないと先着3匹が占領して、いつまでも同じ絵になる)。

> ソヨカ が まり を追いかけた
> ヴォルケイン が あたたか石 の上で丸くなった
> シャドウル が 茂み から顔だけ出している

置いてある要素の座標だけを動かしています。牧場を見ていないあいだは動きません。

`prefers-reduced-motion` が有効なら滑る動きは止まります。

## ドット絵

各モンスターの姿は **15×15 の格子**として、種IDを種にした乱数から生成しています。
**画像ファイルは1枚も持っていません。** セーブにも何も足していません。

- 同じ種はいつ見ても同じ姿(乱数の種が種IDだから)
- 左右対称。片側だけ決めて折り返す
- **ランクが上がるほど大きく**なり、付属物が増える
- 陰影は「上が空いていれば明るく、下が空いていれば暗く」の一行だけ

系統ごとに付属物を変えてあります。

| 系統 | 付属物 |
|---|---|
| 炎・光 | 上へ噴く |
| 草 | 左右対称の葉 |
| 水 | 下へ伸びる鰭 |
| 風 | 横へ張る翼 |
| 岩 | 角ばった突起 |
| 闇 | 上へ伸びる角 |

生成した絵は data URL にして種ごとに覚えておくので、一覧を描き直しても作り直しません。

`canvas` が使えない環境(テスト用のDOM代替など)では、これまでどおり系統の字に戻ります。

## 音

**音声ファイルは1枚も持っていません。** ドット絵と同じで、全部その場で作っています
(WebAudio の発振器と雑音だけ)。

音の中身は `sound.js` の表にあります。1つの音は「小さな音の粒」の並びで、
粒には**形・高さ・長さ・大きさ・頭出しの遅れ**しかありません。

```js
hit:  [{ w:'noise',    f:[1400, 400], t:0.09, g:0.80 },
       { w:'triangle', f:[180, 90],   t:0.13, g:0.72 }],
```

17種類あります。

| どこで | 音 |
|---|---|
| 戦い | 打撃・会心・受け流し・毒・倒れる |
| 探索の結末 | 勝ち・負け・レベルアップ |
| 牧場 | 配合・たまご・買い物 |
| かけっこ | 合図の笛・1着 |
| 大会 | 優勝(いちばん長い音はこれだけ、0.73秒) |
| 画面 | タブ・切り替え |

- **戦いの音は再生と同じ流れで鳴ります。** 記録を1手ずつ再生しているので、
  音も記録から選ぶだけ。勝敗にも数値にも触りません
- **戦いを見せない設定のときは結末だけ鳴らします。** 一手ずつ鳴らすと、
  連打で稼いでいるときに20発ぶんが一度に鳴ってしまうので
- レベルアップの音は、勝ちの音が鳴り終わってから続きます
- 牧場の「音を鳴らす」で切れます。切ったことはセーブされます

書き出して測ってあります(OfflineAudioContext で実際に波を作って計測)。

| | 山の高さ | 長さ |
|---|---|---|
| いちばん大きい音(会心) | 0.21 | 0.18秒 |
| いちばん小さい音(切り替え) | 0.06 | 0.03秒 |
| いちばん長い音(優勝) | 0.14 | 0.73秒 |

どれも 1.0 には遠く、重ねても割れません(いちばん厚い会心で 0.44)。

`AudioContext` は最初に鳴らすときまで作りません(自動再生の制限があるので、
押した指のついでに起こします)。無い環境では黙って何もしないので、
`sound.js` も Node から `require` して中身だけ調べられます。

## 語り

仕組みの外側に、文章を4か所だけ置いてあります。**戦闘や配合の計算には一切影響しません。**

### 系譜

モンスターに**名前をつけられます**(12文字まで)。空にすれば種の名前に戻ります。

配合すると、子が**両親の名前と代**を持って生まれます。

- 代 = 「深いほうの親 + 1」
- 親の名前は配合した瞬間の呼び名で固定される(あとで親を手放しても残る)
- 親がいない個体は、代わりに出自が出る(この地で拾われた / たまご / 最初から)

遺伝値は代を重ねるほど増えていくので、**970という数字はそのまま「5回配合を経た」という記録**です。
系譜はそれを名前で読めるようにしただけで、新しい数字は足していません。

### ライバル

各大会の決勝には、決まったマスターが待っています。

| 大会 | 名前 | 切り札 |
|---|---|---|
| 新芽杯 | ミル(草原の子) | フタバ |
| 沼地杯 | ガイ(沼守り) | アクアム |
| 岩窟杯 | ドロテ(石工) | ゴーレット |
| 尖塔杯 | セレン(嵐読み) | テンペスト |
| 虚無杯 | ノア(深淵の) | ルクスノヴァ |

**難度は変わりません。** 決勝の3匹のうち1匹が固定の種になるだけで、強さはこれまでどおり
こちらの編成に合わせて組まれます。ライバルは手ごたえではなく顔を足すためのものです。

台詞は5種類(初対面・再戦前・勝ったとき・負けたとき・倒したあとの紹介)。
**決勝まで勝ち上がらないと会えず**、それまで名前は伏せられています。負けた回数も数えています。

### エリアの導入文・図鑑の解説文

エリアには一行の導入文が、種には図鑑の一文がついています。
図鑑の文は**見つけた種にだけ**出ます。

## 探索エリア

エリアは「ランクが (エリアのランク − 1) 以上のモンスター」を持っていると解放されます。
ただし解放されても勝てるとは限らないので、レベルを上げてから挑みましょう。

| エリア | 野生のランク | 報酬 |

## 開発

ビルド不要。`index.html` / `style.css` / `game.js` に、
切り出した `race.js`(かけっこ)と `sound.js`(音)、
かけっこ単体の見本 `race.html` です。

`game.js` は `document` が無い環境では `init()` を実行しないので、
Node からロジックだけを読み込んでテストできます(テストコードはリポジトリ外)。

`race.js` と `sound.js` は `module.exports` も持っているので、Node からは
`require('./race.js')` だけで読めます。ゲーム本体は要りません。
