# モンスターマスター

モンスターを配合して新種を生み出すブラウザゲーム。スマホ縦持ち前提。
依存ライブラリなし(バニラ JavaScript)。`index.html` を開くだけで遊べます。

進行状況は `localStorage` に自動保存されます。

## コアループ

```
探索でモンスターと金貨を集める → 同ランク2匹を配合して1つ上のランクへ
   ↑                                              ↓
   └────────── 強い個体で更に深いエリアへ ←────────┘
```

## 4つのタブ

| タブ | できること |
|---|---|
| 牧場 | 手持ちの一覧・詳細確認・にがす、たまごの購入(60 G) |
| 配合 | 2匹を選んで新しい1匹を生む。生まれる種を事前にプレビュー |
| 探索 | エリアと出撃する1匹を選び、自動戦闘。経験値・金貨・仲間を得る |
| 図鑑 | 発見した種の記録(全29種) |

## 配合のルール

**ランク** — 同じランクどうしを配合すると、ランクが1つ上がる(最大5)。
ランクが違う場合は高いほうを引き継ぐだけなので、**同ランクを2匹そろえるのが昇格の唯一の道**です。

**系統** — 親2匹の系統の組み合わせで子の系統が決まります。

| 親の組み合わせ | 子 |
|---|---|
| 同じ系統どうし | 同じ系統 |
| 炎 + 水 | 風 |
| 炎 + 草 | 炎 |
| 炎 + 岩 / 岩 + 風 | 岩 |
| 水 + 草 / 草 + 岩 | 草 |
| 水 + 岩 / 水 + 風 | 水 |
| 草 + 風 | 風 |

隠し系統が2つあります。

- **闇** — ランク3以上の異なる系統どうしを配合すると、25%で発現。以降は闇が親なら子も闇。
- **光** — 闇のランク4以上どうしを配合すると誕生(ランク5固定・全ステータス上昇)。

**遺伝** — 子は親のレベルと遺伝値を引き継ぎます(`(親の遺伝値の平均) + (親のレベル合計 ÷ 4)`)。
親をレベル上限まで育ててから配合すると子が強くなり、**代を重ねるほど強くなる**のがこのゲームの背骨です。

## 系統ごとの特徴

| 系統 | 特徴 |
|---|---|
| 炎 | 攻撃が高く防御が低い |
| 水 | HPが高くバランス型 |
| 草 | 防御が高く攻撃が低い |
| 岩 | HP・防御が高いが鈍い |
| 風 | 素早いがもろい |
| 闇 | 攻撃・素早さが高い |
| 光 | すべて高い |

## 探索エリア

エリアは「ランクが (エリアのランク − 1) 以上のモンスター」を持っていると解放されます。
ただし解放されても勝てるとは限らないので、レベルを上げてから挑みましょう。

| エリア | 野生のランク | 報酬 |
|---|---|---|
| はじまりの草原 | 1 | 10〜20 G |
| ぬかるみの沼 | 2 | 22〜40 G |
| 岩窟回廊 | 3 | 45〜75 G |
| 嵐の尖塔 | 4 | 80〜130 G |
| 虚無の深淵 | 5 | 150〜240 G |

勝つと22%で野生モンスターが仲間になります。牧場は**12匹まで**で、満杯だと連れ帰れません。

## 開発

ビルド不要。`index.html` / `style.css` / `game.js` の3ファイルです。

`game.js` は `document` が無い環境では `init()` を実行しないので、
Node からロジックだけを読み込んでテストできます(テストコードはリポジトリ外)。
