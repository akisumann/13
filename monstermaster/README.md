# モンスターマスター

モンスターを配合して新種を生み出すブラウザゲーム。スマホ縦持ち前提。
依存ライブラリなし(バニラ JavaScript)。`index.html` を開くだけで遊べます。

進行状況は `localStorage` に自動保存されます。

## コアループ

```
探索でモンスターと金貨を集める → 同ランク2匹を配合して1つ上のランクへ
   ↑                                              ↓
   └────────── 強い個体で更に深いエリアへ ←────────┘
```

## 4つのタブ

| タブ | できること |
|---|---|
| 牧場 | 手持ちの一覧・詳細確認・にがす、たまごの購入(60 G) |
| 配合 | 2匹を選んで新しい1匹を生む。生まれる種を事前にプレビュー |
| 探索 | エリアと出撃する1匹を選び、自動戦闘。経験値・金貨・仲間を得る |
| 図鑑 | 発見した種の記録(全29種) |

## 配合のルール

**ランク** — 同じランクどうしを配合すると、ランクが1つ上がる(最大5)。
ランクが違う場合は高いほうを引き継ぐだけなので、**同ランクを2匹そろえるのが昇格の唯一の道**です。

**系統** — 親2匹の系統の組み合わせで子の系統が決まります。

| 親の組み合わせ | 子 |
|---|---|
| 同じ系統どうし | 同じ系統 |
| 炎 + 水 | 風 |
| 炎 + 草 | 炎 |
| 炎 + 岩 / 岩 + 風 | 岩 |
| 水 + 草 / 草 + 岩 | 草 |
| 水 + 岩 / 水 + 風 | 水 |
| 草 + 風 | 風 |

隠し系統が2つあります。

- **闇** — ランク3以上の異なる系統どうしを配合すると、25%で発現。以降は闇が親なら子も闇。
- **光** — 闇のランク4以上どうしを配合すると誕生(ランク5固定・全ステータス上昇)。

**遺伝** — 子は親のレベルと遺伝値を引き継ぎます(`(親の遺伝値の平均) + (親のレベル合計 ÷ 4)`)。
親をレベル上限まで育ててから配合すると子が強くなり、**代を重ねるほど強くなる**のがこのゲームの背骨です。

## ステータス

7種類あります。値は「種のランク × 系統補正 + レベル + 遺伝値」で決まります。

| 表示 | キー | 現状 |
|---|---|---|
| HP | `hp` | 戦闘で使用 |
| MP | `mp` | **未使用**(魔法を入れるときに使う) |
| こうげき | `atk` | 戦闘で使用 |
| ぼうぎょ | `def` | 戦闘で使用 |
| かしこさ | `int` | **未使用**(魔法ダメージ用) |
| すばやさ | `spd` | 戦闘で使用(行動順) |
| きようさ | `dex` | **未使用**(命中・回避用) |

未使用の3つは牧場の詳細画面で半透明表示になります。値自体は系統ごとに差がついているので、
魔法や命中判定を入れた時点でそのまま意味を持ちはじめます。

## 成長係数(F〜S)

ステータスごとに **F・E・D・C・B・A・S の7段階**の成長係数があり、レベルアップでの伸びやすさを決めます。

- **種族としての固定値です。** 遺伝値やレベル、育て方では一切変わりません。同じ種なら誰でも同じ係数です。
- 効くのは**レベルぶんの伸びだけ**。遺伝値は係数と無関係にそのまま加算されます。
- 系統の得意不得意とランクから決まるため、**ランクが低い種ほど全体的に低く**なります。

| グレード | F | E | D | C | B | A | S |
|---|---|---|---|---|---|---|---|
| 1レベルあたりの倍率 | 0.45 | 0.65 | 0.85 | 1.05 | 1.3 | 1.6 | 1.95 |

ランクごとの平均と分布:

| ランク | 平均倍率 | 出現するグレード |
|---|---|---|
| 1 | 0.67 | F〜B(A・Sは出ない) |
| 2 | 0.86 | F〜A |
| 3 | 1.11 | E〜S |
| 4 | 1.36 | D〜S |
| 5 | 1.62 | C〜S(F・Eは出ない) |

同じランクでも系統で偏ります。たとえばランク3なら、シルフィード(風)はすばやさS・きようさA、
ゴーレット(岩)はぼうぎょB・かしこさE。**低ランクの高係数を伸ばすか、高ランクの平均値を取るか**という
選択が生まれます。

係数は牧場の詳細画面で各ステータスの右に表示され、配合プレビューでも生まれる子の得意2つが見えます。

## 系統ごとの特徴

| 系統 | 高い | 低い |
|---|---|---|
| 炎 | こうげき、かしこさ | ぼうぎょ、きようさ |
| 水 | MP、HP、かしこさ | すばやさ |
| 草 | ぼうぎょ、MP | こうげき |
| 岩 | HP、ぼうぎょ | すばやさ、MP、かしこさ |
| 風 | すばやさ、きようさ | HP、ぼうぎょ |
| 闇 | かしこさ、こうげき、MP | — |
| 光 | すべて | — |

## 探索エリア

エリアは「ランクが (エリアのランク − 1) 以上のモンスター」を持っていると解放されます。
ただし解放されても勝てるとは限らないので、レベルを上げてから挑みましょう。

| エリア | 野生のランク | 報酬 |
|---|---|---|
| はじまりの草原 | 1 | 10〜20 G |
| ぬかるみの沼 | 2 | 22〜40 G |
| 岩窟回廊 | 3 | 45〜75 G |
| 嵐の尖塔 | 4 | 80〜130 G |
| 虚無の深淵 | 5 | 150〜240 G |

勝つと22%で野生モンスターが仲間になります。牧場は**12匹まで**で、満杯だと連れ帰れません。

## これから足せること

- 魔法(MP消費・かしこさ依存)と命中/回避(きようさ依存) — 未使用の3ステータスを起動させる
- 特性・スキル(系統ごとの必殺技、相性ダメージ)
- 対戦大会、ランキング
- パーティ戦(複数匹での探索)
- 個体差(性格・才能)、名前をつける
- 系統の追加、種の追加

## 開発

ビルド不要。`index.html` / `style.css` / `game.js` の3ファイルです。

`game.js` は `document` が無い環境では `init()` を実行しないので、
Node からロジックだけを読み込んでテストできます(テストコードはリポジトリ外)。
